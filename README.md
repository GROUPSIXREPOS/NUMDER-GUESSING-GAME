Open your computer and ensure that a C compiler is installed.
Launch a C programming environment such as Code::Blocks, Dev-C++, or Visual Studio Code.
Create a new C programming project or file.
Select C as the programming language.
Create a new source file.
Save the file with a .c extension, for example, guessing_game.c.
Copy the Number Guessing Game code.
Paste the copied code into the source file.
Save the program.
Click the Build or Compile option to compile the program.
Check whether there are any compilation errors.
If errors appear, correct them and compile the program again.
Click Run to execute the program.
The game will display instructions asking you to guess a number between 1 and 10.
Enter your guess using the keyboard and press Enter.
Continue guessing until you get the correct number or use all three attempts. You can choose Y to play again or N to exit.
After choosing N, the program will display a goodbye message and terminate.
